# Airsoft Field Warzone – уебсайт

Статичен сайт (HTML/CSS/JS, без build стъпка). Всички настройки са в **`js/config.js`**.

## Стартиране локално
```
npm install      # само първия път
npm start        # → http://localhost:8080 (+ адрес за телефон в същата Wi-Fi мрежа)
npm test         # Playwright проверки + screenshots в папка screenshots/
```

## Събития от Google Таблица
1. Създайте Google Таблица с колони (първият ред е заглавен):

   | дата | заглавие | описание | снимка | линк |
   |---|---|---|---|---|
   | 25.10.2026 10:00 | Неделна игра | Текст… | (линк към снимка) | (по желание) |

   Можете просто да импортирате `data/events.csv` (Файл → Импортиране).
2. **Дата**: `25.10.2026 10:00`, `25.10.2026` или `2026-10-25 10:00`.
3. **Снимка**: пълен линк към изображение, линк от Google Drive (файлът трябва да е споделен „Всеки с линка“) или празно – тогава се взима снимка от сайта.
4. **Линк**: по желание (напр. Facebook събитие). Без линк бутонът „Запиши се“ отваря формата за запитване.
5. Споделяне → „Всеки с линка може да преглежда“ (или Файл → Споделяне → Публикуване в мрежата → CSV).
6. Копирайте линка в `js/config.js` → `eventsSheetUrl`.

Минали събития се скриват автоматично; отброяването е до най-близкото. Промените в таблицата се виждат при следващо отваряне на сайта (при „Публикуване в мрежата“ Google обновява до ~5 мин).

## „Поискай оферта“
Бутоните отварят прозорец с три варианта: обаждане, Viber и имейл (`email` в config.js).
Viber и имейлът се отварят с готов текст за избраната услуга.

## Видеа
Оригиналните клипове стоят в `assets/video/raw/` (не се качват онлайн).
```
node tools/build-clips.mjs          # всичко
node tools/build-clips.mjs hero     # само фоновия монтаж
node tools/build-clips.mjs action   # само клиповете за „Виж ни в действие“
```
Кои части от кои клипове да влязат се избира в началото на `tools/build-clips.mjs`
(масивите `MONTAGE` и `ACTION`). Скриптът оправя и HDR цветовете от iPhone.
Нов клип в „Виж ни в действие“ = ред в `ACTION` + ред в `actionClips` в config.js.

## Звук
`assets/sfx/aeg-shot.wav` е истински изстрел, изрязан от клип `IMG_6015` (картечницата, 18 изстр./сек).
Звукът при попадение се синтезира в `js/sound.js`.

## TikTok (по желание)
Добавете пълните линкове към видеата в `tiktokVideos`. Видеото се зарежда чак когато посетителят натисне – сайтът остава бърз.

## Снимки
Сложете оригиналите в `assets/src/`, добавете ги в `tools/optimize-images.mjs` и пуснете `npm run images`.

## Качване онлайн
Качете всичко **без** `node_modules/`, `assets/src/`, `assets/video/raw/` (2 GB!), `screenshots/`, `tests/`, `tools/` на какъвто и да е статичен хостинг (Netlify, Cloudflare Pages, GitHub Pages, обикновен хостинг).
